# Banker Tips Professional Upgrade

This package preserves your existing application logic and adds the selected upgrade areas.

## Files
- `server.js` — upgraded Express/MongoDB backend; replace your existing server entry file.
- `public/index.html` — upgraded frontend; put this at `public/index.html`.
- `public/service-worker.js` — offline shell and real push notification handler.
- `public/manifest.webmanifest` — PWA metadata.

Keep your existing `public/images/` assets (especially `bankertipslogo.png`) and all existing environment variables.

## Install dependency
Run in the project root:
```bash
npm install web-push
```
Commit the updated `package.json` and lockfile generated by npm.

## Render environment variables
Keep existing `MONGODB_URI`, `JWT_SECRET`, and OptimaPay credentials. Add:
- `VAPID_PUBLIC_KEY` — generated public VAPID key
- `VAPID_PRIVATE_KEY` — generated private VAPID key (secret)
- `VAPID_SUBJECT` — `mailto:officialbankertips@gmail.com`

Generate the pair once with `npx web-push generate-vapid-keys`. Do not expose the private key in frontend code or commit it to GitHub.

## Implemented
1. Match Centre with date filtering, fixture status, score display, and admin create/edit/delete controls. Fixtures are manually managed; no third-party live-score feed is included.
2. Web Push subscription API, VAPID public-key endpoint, service-worker push display, and generic notifications when published tips are created. Admin broadcast endpoint: `POST /api/admin/notifications/broadcast` with `{ "title": "Banker Tips update", "body": "Your message" }` while authenticated as admin.
3. VIP membership and checkout UI already existed in the source; retained it and preserved the existing membership expiry, payment verification and OptimaPay flows.
4. PWA shell caching, manifest and push-capable service worker.

## Deployment notes
- Deploy backend and frontend together using the same folder layout: `server.js`, `public/index.html`, `public/service-worker.js`, `public/manifest.webmanifest`.
- Preserve existing static assets and dependencies. Do not replace your existing `package.json` with a minimal one. Add `web-push` to dependencies instead.
- Push notifications require HTTPS (Render provides HTTPS) and user permission on each device.
- Match Centre fixtures/scores must be entered/updated by an admin. An automated live-score provider/API is not included.
- Test payments in your existing OptimaPay setup after deployment; this patch intentionally leaves payment handlers unchanged.
